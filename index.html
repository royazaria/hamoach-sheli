שומרים את הקובץ

שומרים את קובץ המוח בתיקיית ההורדות (Downloads), בלי לפתוח אותו ובלי להזיז אותו.

  1. קיבלת בוואטסאפ? פותחים את הוואטסאפ במחשב (האפליקציה או web.whatsapp.com) ולוחצים על הקובץ. הוא נשמר לבד בהורדות.
  2. קיבלת במייל או בדרייב? לוחצים "הורדה". גם ככה הוא נשמר בהורדות.
2

מדביקים שורה אחת

השורה עושה הכל לבד: מתקינה את Obsidian (התוכנה שמציגה את המוח) ואת Claude (עם Claude Code), ופורשת את המוח שלך לתיקייה בשם המוח שלי. מה שכבר מותקן אצלך היא מדלגת עליו.

לוחצים על מקש Windows, כותבים cmd ולוחצים Enter. מעתיקים את השורה, מדביקים בחלון השחור (קליק ימני) ולוחצים Enter. מחכים עד שכתוב All set.

powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://royazaria.github.io/hamoach-sheli/install.ps1 | iex"

אם קופץ חלון ששואל "לאפשר לאפליקציה לבצע שינויים?", לוחצים כן.

לוחצים Cmd + רווח, כותבים Terminal ולוחצים Enter. מעתיקים את השורה, מדביקים (Cmd + V) ולוחצים Enter. מחכים עד שכתוב All set.

curl -fsSL https://royazaria.github.io/hamoach-sheli/install.sh | bash

בסוף נפתחים לבד Obsidian עם המוח שלך, והדף הזה בשלב 3.

✓ ההתקנה הסתיימה. עכשיו שלב 3, ואת מוכנה.
3

מתחילים לעבוד

  1. פותחים את Claude ונכנסים לחשבון (רק בפעם הראשונה).
  2. לוחצים על הלשונית Code ⇐ + New session ⇐ בוחרים את התיקייה המוח שלי.
  3. שולחים לו את ההודעה הראשונה:
תכיר את המוח שלי: תקרא אותו, ותגיד לי בחמש שורות מה אתה יודע על העסק שלי ומה הכי חסר לך.
איפה התיקייה? בתיקייה הראשית של המשתמש שלך. ב-Windows: C: ⇐ Users ⇐ התיקייה עם השם שלך ⇐ המוח שלי. ב-Mac: תיקיית הבית (זו עם האייקון של הבית) ⇐ המוח שלי.

ב-Obsidian רואים את המוח עצמו: המפה, האינדקס וכל פריט. כל מה ש-Claude מוסיף מופיע שם מיד. אם Claude מבקש אישור לקרוא או לכתוב קובץ, מאשרים.

הופיעה הודעה באדום

מצלמים את החלון ושולחים את הצילום למי ששלח לך את המוח.

החלון השחור כותב שהפקודה לא מוכרת

כנראה לא הועתקה כל השורה. לוחצים שוב על "העתקת השורה", מדביקים ולוחצים Enter.

Obsidian לא מראה את המוח

סוגרים את Obsidian ופותחים אותו שוב. אם עדיין לא: Open folder as vault ⇐ בוחרים את התיקייה "המוח שלי".

Claude לא מוצא את התיקייה

ב-+ New session בוחרים את התיקייה ידנית. ב-Windows: C: ⇐ Users ⇐ התיקייה עם השם שלך ⇐ המוח שלי. ב-Mac: תיקיית הבית ⇐ המוח שלי.

Claude אומר שצריך מנוי

Claude Code עובד רק במנוי בתשלום (Pro ומעלה). נכנסים ל-claude.ai ⇐ Upgrade.
